KOMMANDER PUBLIC RELEASE V1973 / 25.48 (CFW)

INSTALL / UPDATE
  Copy the PSP folder onto your memory stick (PSP Go: the internal storage or the card you boot from), merging
  folders. Your settings, library and saves stay. Then start KOMMANDER once: it sets up the overlay and its
  modules on that first start.
  IF THE SHELL IS YOUR ARK LAUNCHER: the launcher copy lives in PSP/SAVEDATA/ARK_01234/VBOOT.PBP and this zip
  does NOT replace it. After copying, start KOMMANDER once from the game list (it updates the launcher copy by
  itself), or SETTINGS > SYSTEM > STARTUP > SET AS DEFAULT LAUNCHER. Consoles on V1576 or later can also update
  in the shell: SYSTEM > UPDATE.

WHAT CHANGED SINCE V1971
  OVERLAY (V12.124)
    SESSION REPORT: the KERNEL RAM bar counts the overlay again on every console (a PSP-2000 / 3000 could read
    OVERLAY 0), and the module loader includes the overlay when it checks what fits.
  LIBRARY
    RESCAN LIBRARY asks QUICK or FULL (START menu and the game TRIANGLE menu). QUICK reads only new or changed
    games, so adding a game takes seconds; FULL reads every game again.
    The list holds still while titles come in: it re-sorts once you stop pressing buttons, and the selected
    game stays selected. While games are read the header shows the count (34/210).

WHAT CHANGED IN V1971 (SINCE V1970)
  ONLINE UPDATE
    SYSTEM > UPDATE crashed (froze, then the PSP turned off) right after COMPARING on many consoles: the list of
    what an update replaces overran its text buffer. Fixed in this shell; the release files are also laid out so
    the older shells (V1948 - V1970) update online without hitting it.
    SEND LOGS sends the network / updater log properly (it sent an empty end of it) and the previous session's
    copy, which is the one a crash leaves behind.
    The PSP no longer dims or sleeps by itself while an update is working.

WHAT CHANGED IN V1970 (SINCE V1949)
  STABILITY
    Closing the overlay after changing a setting (CLOCK LAB above all, any speed - even the same one) froze the
    game: the save ran out of room on the overlay's own stack. Fixed; overclocking from CLOCK LAB works again
    and the SHELL list's CLOCK LAB row shows the real clock.
    The overlay's input thread has twice the stack, and every build now checks every thread's deepest call path
    and every fixed text buffer before it can ship.
    Sleep: a module the system would not unload no longer freezes the first HOME after the wake.
    The SHELL list kept its add-ons (the GTA 60 FPS row among them) even in games that leave little memory.
  LAUNCH GAME
    After a run that did not finish (a freeze, a crash, an early quit) the prompt says so and offers SAFE
    LAUNCH: one start with no komponents. Komponents are no longer switched off by themselves after such a run.
    It also names a komponent that did not start and the ones that did not fit in memory. Wider buttons.
  OVERLAY
    TRACK TICKER (SETTINGS > AUDIO PLAYER): the play time, then the track name, which scrolls when it is long.
    TIME FIRST is the default; SCROLL keeps the old look with the scroll.
    The SUSPEND / RESTORE card has the overlay's own bars and a list that follows the module at work.
    Every SHELL row shows a live value: stats on the HUD, free space, clock, remap, cheats on, the track.
    GTA HUD: GTA HUD STYLE (OVERLAY > GTA HUD STYLE) holds the GTA-drawn HUD's settings on one page; the layout
    no longer puts one stat on top of another.
    LOGS keep 20 sessions, crashes are listed in LOGS/CRASHES.TXT.
  SHELL
    SET AS DEFAULT LAUNCHER turns ARK's autoboot back on when it was switched off outside the shell.
    LOADOUT: easier to read when a row is selected.
    The UMD player plays CSO / ZSO images.
  NEW IN THIS ZIP
    The overlay in the XMB (SETTINGS > SYSTEM > MAINTENANCE > OVERLAY IN THE XMB, PSP-2000 / 3000 only; off
    until you turn it on).
    The GTA 60 FPS komponent (GTA: Liberty City Stories / Vice City Stories): turn it on in LOADOUT.

CHECKED ON HARDWARE (PSP-3000, ARK 5)
  Overclocking from CLOCK LAB and closing the overlay; settings that change and stay; sleep and wake in GTA with
  every module; SET AS DEFAULT LAUNCHER; the SHELL list with its add-ons in GTA; FLAC and MP3 playback.
NOT YET CHECKED ON HARDWARE
  The TRACK TICKER, the new SUSPEND / RESTORE card, the LAUNCH GAME last-run note and SAFE LAUNCH, the PSP-1000
  and PSP Go with this build. Please report anything odd with START > REPORT A PROBLEM.

NOT IN THIS ZIP
  J2ME (Java) games and the other emulator cores.
