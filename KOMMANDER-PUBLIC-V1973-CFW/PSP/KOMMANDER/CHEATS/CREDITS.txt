KOMMANDER - CHEAT DATABASE: CREDITS & SOURCES
=============================================

kommander.db in this folder is ONE cheat database merged from TWO community databases. KOMMANDER did not author any
of these codes - every one of them is the work of the PSP cheat-making community. Full credit and thanks to the
people below; their work is what makes in-game cheats in KOMMANDER possible. Keep this file with the database if you
redistribute it.

  raing3's header asks that his database is not merged into another one and called someone else's. KOMMANDER claims
  none of it: kommander.db's header names him, and every block of TempAR codes inside it is marked
  "# <* from the TempAR database by raing3 *>".

HOW kommander.db WAS MADE (tools/cheatdb_merge.py, 2026-11-05)
  - Per game: the CWCheat Database Plus+ codes first, then the TempAR codes that add something.
  - A code that does the same thing as one already listed (the same writes, whatever its name) is dropped.
  - A TempAR code whose name is taken by a different code is kept as "<name> [TA]".
  - TempAR folders become name prefixes ("Max EXP Codes: Tokio"); TempAR comments become "NOTE: ..." rows.
  - Two different codes with one name in a game are told apart: "<name> (2)" / "<name> [TA 2]" (picks are saved by name).
  - PPSSPP-only rows and "For PPSSPP vX" groups are dropped (emulator-version patches can crash a PSP); PS1
    (GameShark-format) sections are not included - KOMMANDER's engine runs PSP codes only.
  - Result: ~2,803 PSP games, ~104,300 codes and group headers (79,316 CWCheat Database Plus+, 24,997 added from TempAR).

YOUR OWN DATABASE
  Put your own cheat.db (CWCheat or TempAR format; cheats.db or tempar.db also work) beside kommander.db: the overlay's
  CHEATS page shows it as a second tab (L / R). Build its index with tools/cheatdb_index.py for a fast open.

HOW KOMMANDER USES THESE FILES (KOMCHEAT 1.3)
  - Codes are grouped by game ID (_S). KOMMANDER reads the running game's ID and loads only that game's sections,
    through the index (kommander.idx). TempAR's own per-game files (seplugins/TempAR/cheats/<GAMEID>.db) and
    CHEATS/<GAMEID>.db / .txt join the first tab.
  - CWCheat (_L): writes (types 0/1/2), pointer write (6), fills (4/8), 16-bit conditionals (D/E).
    PSPAR / TempAR (_M / _N): writes, conditionals 3-A with D0/D2, pointer loads (B), loops (C0 + D1/D2), the
    offset/data registers (D3-DC), patch (E), copy (F), counter (C5), C6, folders/comments (CF).
    Codes that would run CPU code (C1, C2) or rewrite themselves (C4), and other unsupported types, are shown
    as [ N/A ] and are never applied, never half-applied. Every read and write is range-checked.
  - Your picks are saved per game (<GAMEID>.sel) by cheat NAME and tab.
